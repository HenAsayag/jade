# PROMPT — CLEAN PRODUCTION SPRITES

Using the Jade Match reference assets in this folder, recreate each tile and UI element
as an isolated production sprite on a transparent background.

Preserve the original Jade Match identity:
warm ivory porcelain, jade-green depth/core, softly beveled edges, antique-gold accents,
clean readable symbols, soft directional shadow.

Do not change the icon identity.
Do not add text.
Do not include the reference-board background.
Do not imitate or copy Vita Mahjong artwork.

Tiles should have identical outer dimensions within each family.
Export high-resolution transparent PNG/WebP assets suitable for responsive HTML5 gameplay.
